# 制造型企业固定资产与 IT 一体化平台 — 系统功能说明

> 本文档基于当前代码库与 [MVP.md](MVP.md)、[README.md](../README.md) 整理，描述**已实现**的主要业务能力、角色与模块划分。与「产品说明书」或合同验收条款结合使用时，请以实际部署环境与配置为准。

---

## 1. 系统定位与技术架构

### 1.1 定位

面向制造型企业的 **固定资产全生命周期管理** 与 **IT 基础设施登记/运维入口** 的一体化 Web 平台：资产主数据、企业微信组织与人员镜像、计算机命名与 IPAM、采购与转固、盘点、折旧与报表、ERP 出站队列、审计日志；并扩展 **服务器管理**（多角色纳管：AD、打印、文件共享、Web、数据库等）。

### 1.2 技术栈（摘要）

| 层级 | 技术 |
|------|------|
| 后端 | Node.js、TypeScript、Fastify、Prisma ORM |
| 数据库 | 支持 SQLite（默认）、MySQL、SQL Server（见 [database.md](database.md)） |
| 前端 | 单页应用（Vite + React），开发时代理至后端 API |
| 认证 | JWT；请求头 `Authorization: Bearer <token>` |

### 1.3 部署与访问

- 开发：`npm run dev` 同时启动 API（默认 3000）与前端（默认 5173），浏览器访问 **5173**。  
- 生产：`npm run build` 后 `npm start`，通常 **API 与静态页面同端口**（如 3000）。  
- 健康检查：`GET /health`（无需登录）。

## 2. 用户与权限模型

### 2.1 角色

| 角色 | 说明 |
|------|------|
| **admin** | 管理员：用户与角色、系统参数、资产自定义字段、服务器纳管写操作、删除服务器等 |
| **operator** | 运维：资产新建/编辑、调拨、处置、盘点执行、导出等（具体以菜单 `roles` 配置为准） |
| **viewer** | 只读：仅浏览类菜单；无写接口与写菜单 |

### 2.2 数据范围

资产列表等接口可按登录用户的 **组织范围**（`orgScopeJson`）过滤，避免跨部门越权查看（实现见数据范围服务）。

## 3. 功能模块总览（与侧栏菜单对应）

以下按 **功能分组** 描述；路由前缀一般为 `/app/...`，对应 API `/api/...`。

### 3.1 工作台

- **概览**：`/app/dashboard` — 登录后入口页。

### 3.2 资产管理

- **资产台账**：列表、筛选、详情；资产编号 `assetNo` 唯一。  
- **新建/编辑资产**：分类、位置、状态、组织归属、可选主机名生成（命名策略）、IP 自动分配、人员分配等。  
- **资产分类 / 位置管理**：主数据维护。  
- **资产调拨 / 资产处置**：单据流（含审批步数配置，与 `SystemSetting` 中审批键相关）。  
- **附件**：资产上传附件、下载、删除（权限与接口以路由为准）。  
- **Excel**：导入模板下载、导出台账、批量导入（multipart）。

### 3.3 采购与转固

- **验收待转固 / 采购关联**：采购请求与转固流程相关页面与 API（见 `procurementService` 等）。

### 3.4 盘点管理

- **盘点任务**：创建、启动、完成、行项目。  
- **盘点执行**：实盘录入（含按资产编号录入等）。

### 3.5 折旧与财务

- **折旧汇总**：折旧运行、期间过账等（与财务卡片视图配合）。  
- **财务卡片视图**：财务维度展示。

### 3.6 制造扩展

- **设备与维保 / 模具工装**：扩展业务页面（以实际路由与模型为准）。

### 3.7 企业微信

- **组织与人员**：部门、成员镜像展示。  
- **同步日志**：同步任务状态。  
- **接口**：支持推送部门/用户同步、可选远程拉取全量（依赖环境变量与企微凭证）。

### 3.8 服务器管理（重点）

**入口**：`/app/servers`（列表）、`/app/servers/new`（新建，仅 admin）、`/app/servers/:id`（详情）。

**数据模型**：

- **ManagedServer**：纳管服务器名称、主机、OS 类型、说明、环境、启用、最近探活结果。  
- **ServerCredential**：每台服务器至多一套机器凭据（用户名/密码或密钥类型字段）；密码可经环境变量 **AES 加密存储**。  
- **ServerRoleBinding**：`serverId` + `role` **唯一**；每类角色最多一条绑定。角色包括：`AD`、`PRINT`、`FILE_SHARE`、`WEB`、`DATABASE`。`configJson` 存 JSON 字符串；`isPrimary`（如主域控/主库标记）；`allowWrite`、`allowAutomation`。

**能力摘要**：

| 角色 | 主要能力 |
|------|-----------|
| **AD** | LDAP 连接测试；OU/用户/安全组只读查询；LDAP 写入（建 OU/用户、删对象、改属性、设密码、组成员增删等，受全局写开关 + 实例 `allowWrite`）；LDAPS 与超时参数 |
| **PRINT** | TCP 探活（默认 445、9100 等，可 `configJson.tcpPorts`） |
| **FILE_SHARE** | TCP 探活（默认 445、139） |
| **WEB** | TCP + HTTP(S) HEAD 探活 |
| **DATABASE** | 按 `engine`/`port`/`tcpPorts` 解析端口后 **TCP 探活**（**非** SQL 账号登录验证） |

**整机探活**：`POST /api/servers/:id/probe` 会聚合各角色推导端口（如 AD LDAP、DATABASE 等）做 TCP 探测。

**安全**：全局参数 `server.management.global_write_enabled`、`server.management.global_automation_enabled` 与实例级开关组合使用；审计记录关键操作（密码不落日志）。

**未实现（占位）**：打印机清单与印量、SMB 共享与 ACL、IIS/Nginx 远程管理、数据库 SQL 试连等，需后续协议栈或 Agent。

### 3.9 网络管理

- **网段与 IP**：子网、IP 分配、建议下一空闲 IP（简化 /24 场景）。  
- **IP 分配记录**：历史与分配日志类页面。

### 3.10 命名策略与软件

- **计算机命名策略**：与资产分类等关联的策略与序号。  
- **软件许可**：软件许可台账维护。

### 3.11 报表中心

- **汇总报表**、**导出中心**（导出任务等）。

### 3.12 系统管理

- **用户与角色**（admin）  
- **参数设置**（admin）：`SystemSetting` 键值，含公司名、品牌、审批步数、**服务器管理全局开关**等（见 [settings-keys.md](settings-keys.md)）。  
- **资产自定义字段**（admin）  
- **ERP 对接**：出站队列、资产号映射、处理接口等  
- **审计日志**：操作审计查询

## 4. 系统集成与对外接口

- **ERP**：出站 Webhook 队列、`ErpAssetRef` 映射；处理接口占位或按环境真实投递。  
- **企业微信**：通讯录同步、远程拉取（可选）。  
- **上传与静态资源**：`uploads` 目录（含 branding、server-jobs 等子目录），见 `uploadPaths`。
